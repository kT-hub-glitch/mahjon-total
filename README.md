# 麻雀大会集計ツール

GitHub PagesとSupabaseで動く、麻雀大会向けの簡易集計ツールです。

## できること

- Supabaseで共有する参加者・ゲスト名簿
- 卓と回戦に応じた4名の自動選択（手動変更可能）
- 1〜8回戦の卓組閲覧と選手別の卓検索
- 対局ごとの4人分の素点入力
- 4人の合計点が100,000点のときだけ登録
- スコア入力ページと成績ランキングページの切り替え
- 入力済み対局の修正
- 固定ルールによるポイント計算
- Mリーグルールの同点時順位点分け
- 総合順位、平均ポイント、平均順位、素点平均、1着〜4着回数の集計
- 対局履歴の削除
- 入力内容の自動保存
- Supabaseへの共通保存

## 使い方

`index.html` をブラウザで開くと使えます。

データはSupabaseに保存されます。同じURLを開いた参加者全員で、同じ選手・対局履歴・ランキングを共有します。

## 管理ページ

`admin.html` から、パスワードだけで管理者ログインできます。ログイン後は次の操作ができます。

- 選手の追加、編集、削除
- 点数計算可否、ゲスト、固定卓、同卓するゲスト、NG選手（3人まで）の設定
- 回戦数と各卓の点数計算人数を指定した卓組の自動作成
- 自動作成後の手動入れ替え
- 卓組のSupabaseへの公開保存
- 2チームの所属設定、チーム合計スコア、各卓へのチーム所属選手配置

初回のみ、Supabase DashboardのSQL Editorで `supabase_admin_setup.sql` を実行してください。Authenticationには、メールアドレス `admin@mahjong.local` の管理ユーザーを登録しておきます。管理画面にはメールアドレス入力欄は表示されません。

## GitHub Pagesで公開する場合

1. GitHubで新しいリポジトリを作成します。
2. このフォルダの `index.html`, `style.css`, `app.js`, `README.md` をリポジトリにアップロードします。
3. GitHubのリポジトリ設定から Pages を有効にし、ブランチを `main`、フォルダを `/root` にします。

## 固定ルール

ポイントは次の式で計算します。

```text
(素点 - 返し) / 1000 + 順位点
```

このツールではMリーグ方式として、25,000点持ち、返し `30000`、順位点 `+50 / +10 / -10 / -30` を固定ルールとして使います。同点の場合は対象順位の順位点を分けます。画面ではルール入力なしで、スコアを登録すると自動集計されます。
