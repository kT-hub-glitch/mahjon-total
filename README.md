# 麻雀大会集計ツール

ブラウザだけで動く、麻雀大会向けの簡易集計ツールです。

## できること

- 選手登録
- 半荘ごとの4人分の素点入力
- 返しと順位点を使ったポイント計算
- 総合順位、平均ポイント、トップ回数、ラス回数の集計
- 半荘履歴の削除
- CSV書き出し、CSV読込
- 入力内容の自動保存

## 使い方

`index.html` をブラウザで開くと使えます。

データはブラウザのローカルストレージに保存されます。別の端末へ移す場合は「CSV書き出し」を使ってください。

## GitHub Pagesで公開する場合

1. GitHubで新しいリポジトリを作成します。
2. このフォルダの `index.html`, `style.css`, `app.js`, `README.md` をリポジトリにアップロードします。
3. GitHubのリポジトリ設定から Pages を有効にし、ブランチを `main`、フォルダを `/root` にします。

## 計算式

ポイントは次の式で計算します。

```text
(素点 - 返し) / 1000 + 順位点
```

初期設定は返し `30000`、順位点 `+50 / +10 / -10 / -30` です。
