# 麻雀大会集計ツール

GitHub PagesとSupabaseで動く、麻雀大会向けの簡易集計ツールです。

## できること

- 選手登録
- 対局ごとの4人分の素点入力
- 4人の合計点が100,000点のときだけ登録
- スコア入力ページと成績ランキングページの切り替え
- 入力済み対局の修正
- 固定ルールによるポイント計算
- Mリーグルールの同点時順位点分け
- 総合順位、平均ポイント、平均順位、素点平均、1着〜4着回数の集計
- 対局履歴の削除
- 入力内容の自動保存
- Supabaseへの共通保存

## 使い方

`index.html` をブラウザで開くと使えます。

データはSupabaseに保存されます。同じURLを開いた参加者全員で、同じ選手・対局履歴・ランキングを共有します。

## GitHub Pagesで公開する場合

1. GitHubで新しいリポジトリを作成します。
2. このフォルダの `index.html`, `style.css`, `app.js`, `README.md` をリポジトリにアップロードします。
3. GitHubのリポジトリ設定から Pages を有効にし、ブランチを `main`、フォルダを `/root` にします。

## 固定ルール

ポイントは次の式で計算します。

```text
(素点 - 返し) / 1000 + 順位点
```

このツールではMリーグ方式として、25,000点持ち、返し `30000`、順位点 `+50 / +10 / -10 / -30` を固定ルールとして使います。同点の場合は対象順位の順位点を分けます。画面ではルール入力なしで、スコアを登録すると自動集計されます。
